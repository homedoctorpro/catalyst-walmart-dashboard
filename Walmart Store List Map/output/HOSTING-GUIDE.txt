OPTION 1: Netlify (Easiest - Drag & Drop)
═══════════════════════════════════════════════════════════════

1. Go to: https://app.netlify.com/drop

2. Drag and drop your "index.html" file onto the page

3. Done! You'll get a free URL like:
   https://random-name-12345.netlify.app

4. (Optional) To change the URL:
   - Click "Site settings"
   - Click "Change site name"
   - Choose your own name: catalyst-pet-stores.netlify.app


═══════════════════════════════════════════════════════════════
OPTION 2: GitHub Pages (Most Popular)
═══════════════════════════════════════════════════════════════

1. Create a free GitHub account at: https://github.com/signup

2. Create a new repository:
   - Click the "+" button (top right)
   - Select "New repository"
   - Name it: "catalyst-pet-map" (or anything you want)
   - Make it Public
   - Click "Create repository"

3. Upload your file:
   - Click "uploading an existing file"
   - Drag and drop "index.html"
   - Click "Commit changes"

4. Enable GitHub Pages:
   - Go to Settings
   - Click "Pages" in the left sidebar
   - Under "Source", select "main" branch
   - Click "Save"

5. Your site will be live at:
   https://YOUR-USERNAME.github.io/catalyst-pet-map/
